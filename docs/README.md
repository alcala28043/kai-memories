# Kai Memories — Portable Long‑Term Memory Vault for Agents

Kai Memories is a portable long‑term memory vault designed to be used with OpenClaw (or similar agent frameworks) and Obsidian.

It is **not** an official OpenClaw plugin.  
Instead, it is a self‑contained memory module that you can:

- Fork privately on GitHub
- Clone on any machine
- Open as an Obsidian vault
- Connect to your agent via tools and skills

## What this repository contains

- `memory/` — Structured Obsidian vault with atomic notes.
- `tools/` — Python tools that let an agent read and write memory.
- `skills/` — LLM instructions that teach the agent how to use the memory system.
- `INSTALL.md` — How to set it up.
- `USAGE.md` — How to use it with an agent.
- `.gitignore` — To keep the repo clean.

Kai Memories is meant to be used as a **private, Git‑synced memory vault**, not as a public ClawHub plugin.
