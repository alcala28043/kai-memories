# Memory Index Skill

You can use the memory index tool to refresh or rebuild the search index.

## When to use it

- When many notes have been added manually in Obsidian.
- When the index seems outdated.
- When search results appear incomplete.
- After reorganizing folders or renaming files.

## How to use it

Call the tool with:

- `"mode": "incremental"` to update only changed files.
- `"mode": "full"` to rebuild the entire index.

## Examples

- “Rebuild the memory index.”
- “Refresh the index after adding new notes.”
- “Update the index incrementally.”
